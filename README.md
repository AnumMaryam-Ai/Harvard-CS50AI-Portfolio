# My AI Project Portfolio

Hello! This repository highlights the 8 Artificial Intelligence projects I built using Python while completing Harvard University's CS50AI course. 

##  The 8 AI Projects I Completed:

1.Minesweeper:Built an AI agent that uses logical inference and subset evaluation to safely flag hidden mines without guessing.
2.Knights:Solved classic logic puzzles ("Knights and Knaves") by representing clues as propositional logic sentences.
3.Degrees:Found the shortest path between Hollywood actors using Breadth-First Search (BFS) graph algorithms.
4.Tic-Tac-Toe:Programmed an unbeatable AI player using the recursive Minimax framework.
5.PageRank:Rebuilt Google’s foundational ranking algorithm using Markov Chain random surfer models.
6.Heredity:Designed a Bayesian Network to calculate conditional joint probabilities in family genetic histories.
7.Shopping:Trained a Machine Learning model using K-Nearest Neighbors to predict online consumer buying intent.
8.Nim:Taught an AI to play the mathematical game of Nim perfectly using Reinforcement Learning (Q-learning).
